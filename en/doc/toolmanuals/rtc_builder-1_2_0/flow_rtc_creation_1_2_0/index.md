### RTC Creation Flow (for the C++ Language)

When creating an RTC in the C++ language, the following tools are required.
- [CMake](http://www.cmake.org/)
- [Visual Studio](https://visualstudio.microsoft.com/ja/downloads/?utm_source=mscom&utm_campaign=msdocs) (Windows)

Also, by installing the following software, you will be able to generate documentation and installers.

- [Doxygen](http://www.doxygen.jp/)
- [WiX](http://wix.sourceforge.net/) (Windows)


1. RTCBuilder code generation outputs the source code template and the files required as input for CMake.
1. From the code generated by RTCBuilder, CMake generates build files suitable for the user's development environment, such as Visual Studio solution files or GCC Unix Makefiles.
1. Components (dll or so files) are generated from the build files and source code generated by CMake.




### Limitations
RTCBuilder was developed for OpenRTM-aist. Operation with other RTC platforms is not assumed.
