## Introduction

The procedure for creating an rpm package is shown below.<br>

## Creation Procedure When Not Including doxygen Documentation
* By default, the documentation build is OFF, so it is not generated.

- For a C++ RTC

```
 $ cd プロジェクトディレクトリー
 $ mkdir build
 $ cd build
 $ cmake ..
 $ make
 $ cpack
```

- For a Pyrhon RTC

```
 $ cd プロジェクトディレクトリー
 $ mkdir build
 $ cd build
 $ cmake ..
 $ cpack
```

## Creation Procedure When Including doxygen Documentation
Change the following line in CMakeLists.txt directly under the project directory from OFF to ON.<br>
For a C++ RTC, this is around line 86, and for a Python RTC, around line 77.

```
 option(BUILD_DOCUMENTATION "Build the documentation" ON) ※この行の OFF を ON に書き換えます。(デフォルトは OFF)
```

- For a C++ RTC

```
 $ cd プロジェクトディレクトリー
 $ mkdir build
 $ cd build
 $ cmake ..
 $ make
 $ make doc
 $ cpack
```

- For a Pyrhon RTC

```
 $ cd プロジェクトディレクトリー
 $ mkdir build
 $ cd build
 $ cmake ..
 $ make doc
 $ cpack
```

[Notes]<br>
If you turn ON the documentation build and run "cpack" without running "make doc", the following error will occur.

```
 CMake Error at /home/プロジェクトディレクトリー/build/doc/cmake_install.cmake:36 (file):
 file INSTALL cannot find
 "/home/プロジェクトディレクトリー/build/doc/html/doxygen/html".
```

## rpm Package Storage Location and File Name
If it is created successfully, it will be saved in [build] inside the project directory.<br>
The file name will be "RTC project name-RTC version number-architecture".<br>

(Example) Flip-1.2.0-x86_64.rpm<br>
* The architecture will be [i686] or [x86_64].<br>

## Installing and Uninstalling an rpm Package
### Installation
Run the following command to install.
```
 $ cd プロジェクトディレクトリー/build 
 $ sudo rpm -i Flip-1.2.0-x86_64.rpm
```

### Uninstallation
Run the following command to uninstall.
```
 $ sudo rpm -e Flip
```

## IDL Compilation Processing for Python RTCs with Service Ports
Python RTCs with service ports execute IDL compilation when the package is installed.
This behavior is implemented by postinst.in and prerm.in in the project directory during IDL compilation execution, so be careful not to delete these files, as the function will stop working.<br><br>
