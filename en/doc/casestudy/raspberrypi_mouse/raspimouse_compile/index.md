This page explains how to build projects on Ubuntu using Code::Blocks.

#contents

## Environment Setup

Code::Blocks can be installed with the following command.

```bash
sudo apt-get install codeblocks
```

If Doxygen and CMake are not already installed, install them using the following command.

```bash
sudo apt-get install doxygen cmake
```

## Build Procedure

### CMake

Move to the folder containing the code generated by RTC Builder and execute the following commands.

This will generate the required build files in the **build** directory.

```bash
mkdir build
cd build
cmake . -G "CodeBlocks - Unix Makefiles"
```

### Running Code::Blocks

Open the **~.cbp** file in the **build** directory.
