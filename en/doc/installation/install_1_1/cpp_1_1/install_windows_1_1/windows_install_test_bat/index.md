## What Is windows_installer_test.bat?

This script checks the configuration of a Windows environment in which OpenRTM-aist is installed. It was created to check the installation environment of OpenRTM-aist Version 1.1.2, but it can also be used in environments where an earlier version is installed.<br>
Simply double-click the script to run it. The results are output to log files, allowing you to check the following information.

- Check whether OpenRTM-aist is installed
  - If it is installed, the directory structure generated by the tree command is written to a separate file

- Check the system environment variables

- Check the Path

- Check whether OpenRTM-aist-Python and rtshell are installed
  - If they are installed, the directory structure generated by the tree command is written to a separate file

- Check the custom installation list

## Execution

Double-click the downloaded windows_installer_test.bat file. A Command Prompt window is displayed while the script is running, but it closes when execution is complete. Please wait until it closes.

### Custom Execution (Using Cygwin)

The installed directory structure is written to a log file using the tree command.<br>
If the Cygwin tree command is installed in your environment, modify the following setting at the beginning of the script to match your environment. If `%CYGWIN_DIR%\bin\tree.exe` does not exist, the standard Windows tree command is used.<br>

When the Cygwin tree command is installed, the `yymmdd-hhmmss_'Python directory'-dir.tree` log containing the installation directory structures of OpenRTM-aist-Python and rtshell is more compact. This is because the output options allow you to specify how many directory levels to display.
The standard Windows tree command does not allow the directory depth to be specified, so the entire structure starting from the top of the Python directory in which OpenRTM-aist-Python is installed is included. Therefore, only directory names are output to the log.


```
 set CYGWIN_DIR=C:\Cygwin64
```

## Log Files

All execution results are output to log files. They are stored in the `log` folder in the same directory as the script. If the folder does not exist, it is created automatically.<br>
For example, you can run this script from a USB flash drive and check the results on another PC.

#### Checking the OpenRTM-aist Installation (Checking the Program Files Folders)

The script checks whether the `C:\Program Files\OpenRTM-aist` and `C:\Program Files (x86)\OpenRTM-aist` directories exist. Even if OpenRTM-aist has already been uninstalled, the directory may remain if files generated after installation, such as `rtc***.log`, still exist. If a directory is shown as `exist!` but each of the C++, Python, and Java Examples is shown as `not installed`, this may be the case. Check the tree file.

- Example output from an environment in which Version 1.1.2 is installed
  - The following result indicates that only the 32-bit version is installed
  - The directory structure of C:\Program Files (x86)\OpenRTM-aist is saved to `log\20160906-141617_pfile_x86.tree`
  - The Version 1.1.2 number is obtained from the RTM_ROOT setting
