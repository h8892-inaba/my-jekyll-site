### Windows Installer

Only the 64-bit version is available. Running the downloaded MSI installs the C++ version, Python version, Java version, OpenRTP, rtshell, OpenCV 4.13.0, omniORB 4.3.4, and JRE 8.

If you are using Microsoft Edge and are unable to download the file, please refer to the following page for instructions.
- [Get Started with OpenRTM-aist in 10 Minutes! - Downloading OpenRTM-aist]({{ site.baseurl }}/ja/doc/installation/lets_start#toc2)  

The required software, Visual Studio and Python, supports the following versions:
- Visual Studio (2019, 2022, 2026)
- Python (3.10, 3.11, 3.12, 3.13, 3.14)

On Windows, make sure that the Python version number is displayed at the command prompt. <br>
If it is not displayed, please refer to [Python Version Number Is Not Displayed After Installing Python on Windows]({{ site.baseurl }}/ja/doc/faq/faq_install#toc1).

For installation instructions, please refer to [Installing OpenRTM-aist 2.1 on Windows]({{ site.baseurl }}/ja/doc/installation/install_2_1/install_win_2_1). <br>
If you are installing OpenRTM-aist for the first time, please refer to [Get Started with OpenRTM-aist in 10 Minutes!]({{ site.baseurl }}/ja/doc/installation/lets_start).

### Linux Packages

<!-- 既に1.2系をご利用されている場合は、インストール前に [[2.1系での変更点:/ja/doc/installation/install_2_1/install_linux_2_1/install_2_1#toc0]] をご覧ください。　&br; -->
On Ubuntu 22.04 and 24.04 (amd64 and arm64 environments), paste and execute the following command at the shell prompt to install the C++ version, Python version, Java version, OpenRTP (amd64 only), rtshell, and JDK 8.

$ bash <(curl -s https://raw.githubusercontent.com/OpenRTM/OpenRTM-aist/master/scripts/openrtm2_install_ubuntu.sh)


For installation instructions, please refer to [Installing OpenRTM-aist 2.1 on Linux]({{ site.baseurl }}/ja/doc/installation/install_2_1/install_linux_2_1).

### Raspberry Pi OS Packages

<!-- 既に1.2系をご利用されている場合は、インストール前に [[2.1系での変更点:/ja/doc/installation/install_2_1/install_raspbian_2_1#toc0]] をご覧ください。　&br; -->

On Bookworm (64-bit environment), paste and execute the following command at the shell prompt to install the C++ version, Python version, Java version, and rtshell.

$ bash <(curl -s https://raw.githubusercontent.com/OpenRTM/OpenRTM-aist/master/scripts/openrtm2_install_raspbian.sh)


For installation instructions, please refer to [Installing OpenRTM-aist 2.1 on Raspberry Pi OS]({{ site.baseurl }}/ja/doc/installation/install_2_1/install_raspbian_2_1).
