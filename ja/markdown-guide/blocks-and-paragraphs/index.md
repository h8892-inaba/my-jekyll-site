## 左寄せ センタリング 右寄せ

```
<div align="left">文字列の左寄せ</div>
<div align="center">文字列のセンタリング</div>
<div align="right">文字列の右寄せ</div>
```

で、左寄せ・センタリング・右寄せができます。

<div align="left">文字列の左寄せ</div>
<div align="center">文字列のセンタリング</div>
<div align="right">文字列の右寄せ</div>

## 行間あけ

```
 <br>
```

行頭で記述すると、ブロック要素間またはブロック要素内で行間を開けることができます

ここと
<br>
ここの間に改行が入ります。
