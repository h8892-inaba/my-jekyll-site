## Press Releases

### September 15, 2010:[Development of "HRP-4," a Research and Development Platform for Working Humanoid Robots](http://www.aist.go.jp/aist_j/press_release/pr2010/pr20100915/pr20100915.html?utm_source=twitterfeed&utm_medium=twitter)


<!-- div align="right"><a href="http://www.aist.go.jp/aist_j/press_release/pr2010/pr20100915/photo.jpg"><img src="http://www.aist.go.jp/aist_j/press_release/pr2010/pr20100915/photo.jpg" width="30%;" align="right"></a></div-->

Kawada Industries, Inc. and AIST have jointly developed "HRP-4," a new platform for the research and development of working humanoid robots. The HRP-4 control system utilizes a Linux kernel with the RT-Preempt patch and the OpenRTM-aist software platform. This allows for the use of numerous robot system software assets from Japan and abroad, including the open-source robot simulator OpenHRP3.


The motion control software consists of a group of RT-Components incorporating motion control technologies cultivated through the HRP series as core logic. This enables efficient development using RT Middleware-compatible development tools and existing RT-Components. By combining various existing RT Middleware-compatible software—such as OpenHRI, which provides RT-Components for speech recognition, synthesis, and dialogue control required for communication functions, or RT-Components using the OpenCV image processing library—it is possible to easily build a wide variety of applications.

### January 28, 2010:[Release of RT Middleware "OpenRTM-aist" Version 1.0](http://www.aist.go.jp/aist_j/press_release/pr2010/pr20100128/pr20100128.html)

AIST has developed and released the latest C++ version (1.0) of OpenRTM-aist (Open Robot Technology Middleware implemented by AIST), a software platform designed to freely combine various robotic functional elements via communication networks, under an open-source license. OpenRTM-aist modularizes robotic elements such as sensors, motors, robot arms, and mobile platforms at the software level. By enhancing reliability and reusability, it enables the efficient development of robot systems.
The interface specification for the "RT-Component" (the basic unit of a module) complies with the RTC (Robotic Technology Component) Specification Version 1.0, which was officially adopted as a standard by the international standards organization OMG™ (Object Management Group™). OpenRTM-aist is the world’s first implementation to comply with the OMG RTC specification.

### May 26, 2010:[Presenting a Housing Environment Model for Independent Living for Persons with Disabilities](http://www.aist.go.jp/aist_j/press_release/pr2010/pr20100526/pr20100526.html)

AIST has developed system integration technology that allows persons with disabilities to combine and manage various welfare devices independently. We proposed and conducted verification tests on a housing environment model tailored to individual needs. In the system tested, input/output devices with various control methods are networked using RT (Robot Technology) Middleware. This allows devices to be easily added to or removed from the network and enables cooperative operation between devices, making it possible to combine equipment according to the user's requirements.
